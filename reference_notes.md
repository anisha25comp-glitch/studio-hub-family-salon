# Reference site findings: A ONE Unisex Salon

The supplied reference website presents a strong feature-first salon structure rather than a simple brochure page. Its main patterns are a compact utility strip, a clear navigation with Menu, Offers, Membership, Find Us, Instagram, and Book Now, an editorial hero with primary appointment and menu CTAs, and utility actions for calling and directions.

The service menu is organized into numbered categories with separate subgroups and an add-to-appointment action for each service. The categories visible on the reference include women’s hair, skin and beauty, spa and nails, and men’s grooming. The site also separates team/providers, booking slot selection, work/gallery content, offers/packages, membership, location, and Instagram/social proof.

The booking section uses service selection, date selection, provider selection, selectable time slots, customer name and phone fields, and a WhatsApp handoff with appointment details ready to send. The reference explicitly communicates that final confirmation happens on WhatsApp.

The revised Studio Hub site will borrow this information architecture and interaction model, but will use only The Studio Hub’s supplied service menu, prices, identity, address, contact details, and Instagram handle. It should not copy the reference brand, wording, imagery, logo, or testimonials.
